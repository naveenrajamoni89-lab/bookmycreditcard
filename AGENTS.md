# Design preferences

- Use black primary buttons and white secondary buttons with black borders throughout the website, including credit card actions. Adapt the shape and size to the surface; use the Explore palette without copying every button treatment.
- Avoid decorative arrows on buttons and links, especially diagonal arrows. Keep directional icons only when they explain an actual navigation or disclosure control.
- Keep page designs professional and editorial: clear typography, meaningful content, restrained surfaces, real bank logos and card artwork. Avoid repeated rounded feature boxes, gradients and unnecessary shadows.
- Do not use Playwright unless the user asks to resume browser testing.
